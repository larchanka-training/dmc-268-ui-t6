Это визуально значимые решения, их согласование входит в approval этого плана. Не подменяем

Поля Input/InputNumber получают явные `errorActiveShadow`/`warningActiveShadow` шириной 3px
цвета focus-ring §7. Проверить как error, так и warning; error/warning border сохраняется.

Для Pagination сначала проверяем компонентный `lineWidthFocus: 2`: установленная antd
использует `genFocusOutline` на разных узлах (номер страницы, previous/next/jump).
Нельзя заранее фиксировать селектор на внутреннем `a` или менять ширину обычной рамки.
Если токен не достигает реального focus target, допускается только узкое CSS-правило,
подтверждённое DOM и computed styles, с регрессионным тестом селектора.

Для Segmented вводим общий компонент `shared/ui/Segmented` с обязательным осмысленным
`aria-label`. В установленном `@rc-component/segmented@1.4.0` корень имеет `tabIndex=0`,
радиоэлементы объединены `name`, а arrow-handler стоит на input. Публичный `tabIndex={-1}`
переопределяет корень через props; это основной вариант для одного Tab-стопа на выбранном
native radio. Сначала доказать в браузере Tab/Shift+Tab, стрелки, checked, callback и
фокус после переключения. Не добавлять querySelector/ref/effect для переписывания DOM,
пока публичные props решают задачу. Если выявится дефект стрелок/фокуса native radio,
зафиксировать воспроизведение и выбрать минимальное решение на публичном API до интеграции.
В приложении — имена «Фильтр репозиториев» и «Вид диффа: <имя файла>», включая повторяющиеся
переключатели разных файлов. Обновляем и Storybook/Overview, чтобы витрина учила тому же API.

Storybook Docs получает тему из актуального канала globals/context, а не из устаревшей
строки iframe URL при каждом remount. Не вводим второй источник истины и не патчим manager
URL вручную. Реальное API установленного Storybook проверяет development; чтение URL может
служить только первоначальным fallback, который не побеждает актуальное значение.

Контраст считается на `theme.getDesignToken(buildTheme(mode))` через публичный API shared/ui
в `widgets/diff-viewer/lib/diffTheme.test.ts`. Для всех существующих SURFACES сохраняем
порог **4.5:1 текста строки** и альфа-композицию. Существующие проверки syntax 3:1 не
ослаблять; переход на реальную тему может обнаружить прежний дефект. Непроходящий цвет
исправляем в соответствующем источнике палитры/mapper, не возвращаем тест на stock antd и
не снижаем пороги. Общую норму текста §3 в документации не ослабляем.
