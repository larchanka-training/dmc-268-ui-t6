# Reviewer UI

Это дизайн-система Reviewer, основная UI-система продукта. На ней строятся все интерфейсы
приложения: и существующие экраны, и новые.

Внутри два слоя:

- **Ant Design в нашей теме.** Кнопки, поля, таблицы, модальные окна, меню. Библиотека та же, что
  и раньше, но цвета, размеры и поведение приведены к одному виду (Flat Console).
- **Свои компоненты.** То, чего в библиотеке нет в нужном виде: тег со статусом, заголовок
  страницы, таблица с нашими настройками, логотип.

## Зачем она нужна

- **Быстрее строить интерфейсы.** Базовые компоненты уже выглядят правильно, их не нужно
  оформлять заново.
- **Единый вид.** Все экраны берут цвета, размеры и состояния из одного источника.
- **Аккуратно сразу.** Новый экран, собранный из этих компонентов, не требует отдельной работы над
  оформлением.

## Главное правило

Базовые компоненты берутся только отсюда: из Ant Design в нашей теме и из `src/shared/ui`.
На экране их не перекрашивают и не оформляют заново.

Отдельно пишутся только составные компоненты под конкретный экран, которых здесь нет: таблица
репозиториев, дерево действий прогона, просмотр диффа. Они собираются из базовых.

Если нужного компонента ещё нет, его сначала подгоняют по чеклисту из «Спецификации», добавляют
сюда историю и только потом используют на экране.

## Как пользоваться

```tsx
import { Button } from 'antd'

import { PageHeader, Tag } from '../../shared/ui'

<PageHeader title="Прогоны" actions={<Button type="primary">Обновить</Button>} />
<Tag tone="success">succeeded</Tag>
```

Всё приложение оборачивается в `DesignSystemProvider` один раз. Он подключает тему, токены и
правки поверх Ant Design. Тема переключается его параметром `mode`. В Storybook для этого есть
переключатель «Тема» в верхней панели.

## Что внутри

- **Начало / Правила**: когда какой компонент и вариант применять.
- **Начало / Спецификация**: все числа и чеклист для нового компонента.
- **Начало / Обзор**: цвета, типографика и компоненты на одной странице.
- **Свои компоненты**: то, что написано в этом репозитории.
- **Ant Design**: компоненты библиотеки в нашей теме, со всеми состояниями.
