# Правила применения

Короткая версия для того, кто собирает экран. Все числа и полный чеклист лежат в «Спецификации».

## Откуда брать компоненты

1. Нужен базовый компонент: берём из Ant Design или из `src/shared/ui`.
2. Его нет или он выглядит не так: подгоняем по чеклисту из «Спецификации», добавляем историю,
   потом используем.
3. Нужен составной компонент под конкретный экран: пишем в `widgets` или `features` из базовых.

Нельзя: перекрашивать компонент на экране, подключать компонент из другой библиотеки, задавать
цвета и размеры числами, переопределять классы `.ant-*` вне `styles/antd.css`.

## Кнопки

- На экране одна главная кнопка. Остальные обычные или текстовые.
- `danger` только для действий, которые что-то прерывают или удаляют.
- Кнопке с одной иконкой обязателен `aria-label`.
- Пока идёт запрос, кнопка показывает загрузку, а не исчезает.

## Теги

| Вид                     | Когда                                                                   |
| ----------------------- | ----------------------------------------------------------------------- |
| С точкой (по умолчанию) | Всё, что сообщает состояние: статус прогона, важность high, medium, low |
| Заполненный (`solid`)   | Только то, что требует действия: `critical` и блокирующий вердикт       |
| Контурный (`outline`)   | Метаданные: ветка, движок, `summary-only`                               |

Заполненных тегов на экране должно быть один-два.

## Рамки

Рамка нужна данным с чёткой границей: таблице, диффу, блоку метаданных. Заголовок страницы, кнопки,
поиск и фильтры лежат прямо на странице, без карточки вокруг.

## Выбор из вариантов

| Сколько вариантов                         | Компонент   |
| ----------------------------------------- | ----------- |
| Включено или выключено, применяется сразу | `Switch`    |
| Два-четыре вида одних и тех же данных     | `Segmented` |
| Несколько вариантов, все видны            | `Radio`     |
| Длинный список                            | `Select`    |

## Выбранное состояние

Выбранный пункт меню, строка, сегмент или страница всегда серые, не синие. Синий остаётся для
главного действия, ссылок и фокуса.

## Сообщения

- `Alert` для сообщения внутри страницы.
- Пустое состояние объясняет, что сделать дальше, и даёт кнопку.
- Пока данные грузятся, показываем `Skeleton` или `Spin`, а не пустоту.
