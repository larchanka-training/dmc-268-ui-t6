Живой прогон (`ISSUE_GRAPH_FIXTURE_DIR` не задан), только показать: ничего не публикуется. Данные
меняются, поэтому проверяются инварианты, а не номера задач.

Команда, ровно одна:

```bash
.agents/skills/issue-graph/scripts/issue_graph.py --milestone "Спринт 4"
```

- Нет `--publish-to`: ни одного комментария, ни POST, ни PATCH.
- Код выхода 0. Код 1 (в спринте цикл) — не сбой: отчёт напечатан, агент показывает его и
  начинает с цикла.
- Ответ начинается с тревог из отчёта: разделы «Циклы» и «In Progress с открытым блокером». Если
  раздел пуст, одна строка об этом («Циклов нет») — и дальше по порядку.
- Дальше слой 1 из «Слои: что можно брать параллельно» — это и есть «можно брать сейчас»; затем
  «Критический путь» и «Без связей».
- Каждый номер задачи в ответе есть в отчёте, список слоя 1 и цепочка критического пути
  совпадают с отчётом.
- В конце предложение, а не действие: могу опубликовать граф в issue «Спринт N» (#261) —
  `--publish-to 261`.

Не делает:

- Не публикует граф без просьбы и не добавляет `--publish-to` «заодно».
- Не придумывает порядок, если в отчёте «Не считаются: в графе цикл.», — слои и критический путь
  при цикле не пересказываются.
- Не правит связи, статусы и поля доски, не комментирует чужие задачи.
- Не подставляет другое название майлстоуна, если «Спринт 4» не найден.
