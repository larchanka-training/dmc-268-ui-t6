---
title: Quickstart
description: Install the GitHub App and get your first review.
icon: Rocket
---

<Steps>
<Step>

### Sign in

Open the <AppLink /> and click **Sign in with GitHub**. If you installed the app before signing
in, your next sign-in links that installation to your account.

</Step>
<Step>

### Install the GitHub App

On <AppLink path="/repositories">**Repositories**</AppLink>, click **Connect repository** (on an empty list, **Install GitHub App**) and pick the repositories on GitHub. Each one
is connected with reviews on, and gets an `ai-review` label.

</Step>
<Step>

### Refresh access

Back in the dashboard, click **Refresh access**. The repository can take a few minutes to
appear.

</Step>
<Step>

### Add the label

On a pull request in that repository, add the label `ai-review`. On GitHub, adding labels needs
triage access or higher.

</Step>
<Step>

### Get the review

Once CI passes, the Reviewer bot posts its review. If the repository has no CI, it starts about
two minutes after the label or the latest push, whichever is later. Follow each step in
<AppLink path="/runs">**Runs**</AppLink> in the dashboard.

</Step>
</Steps>

Nothing happened? See [No review appeared](/faq#no-review-appeared).
