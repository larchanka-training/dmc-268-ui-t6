You need a GitHub account with rights to install apps on the repositories you want reviewed.
The dashboard is in Russian; this guide gives each label with its English meaning.

<Steps>
<Step>

### Sign in to the dashboard

Open the <AppLink /> and click **Войти через GitHub** (Sign in with GitHub). GitHub asks you to
authorize the Reviewer app, then sends you back to the dashboard.

Sign in before you install the app. Reviewer links an installation to your account when you
sign in, so repositories installed by someone who never signed in show up later.

</Step>
<Step>

### Install the GitHub App

On **Репозитории** (Repositories), click **Подключить репозиторий** (Connect repository). The
GitHub install page opens in a new tab. Pick the account and the repositories, then confirm.

Every repository you select is connected with reviews turned on. Reviewer also creates the
`ai-review` label in each of them.

</Step>
<Step>

### Refresh access

Back in the dashboard, click **Обновить доступ** (Refresh access). This signs you in to GitHub
again so the dashboard sees the new installation. A new repository can take a few minutes to
appear; click **Обновить** (Refresh) if it is not there yet.

Check that the **Ревью** (Review) switch is on for the repository.

</Step>
<Step>

### Add the `ai-review` label to a pull request

Open a pull request in a connected repository and add the label `ai-review`. The label must
match exactly.

</Step>
<Step>

### Let CI finish

By default Reviewer waits until every other check on the head commit has passed. If the
repository has no CI at all, the review starts about two minutes after you add the label. See
[CI waiting](/docs/how-it-works#ci-waiting) to change this.

</Step>
<Step>

### Read the review

The `AI Review` check run appears on the pull request while the review runs. When it is done,
the Reviewer bot posts its review with inline comments and a summary. To see every step, open
**Прогоны** (Runs) in the dashboard.

</Step>
</Steps>
