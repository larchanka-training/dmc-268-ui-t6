You need a GitHub account that can install apps on the repositories you want reviewed.

<Callout title="The dashboard is in Russian for now">
  An English version is planned. The button and page names below are English translations of
  the current labels.
</Callout>

<Steps>
<Step>

### Sign in first

Open the <AppLink /> and click **Sign in with GitHub**. GitHub asks you to authorize the
Reviewer app, then sends you back.

Sign in before you install the app. Reviewer links an installation to your account when you
sign in, so an app installed by someone who never signed in shows up only later.

</Step>
<Step>

### Install the GitHub App

On **Repositories**, click **Connect repository**. The GitHub install page opens in a new tab.
Pick the account and the repositories, then confirm.

Every repository you pick is connected with reviews turned on, and Reviewer creates the
`ai-review` label in it.

</Step>
<Step>

### Refresh access

Back in the dashboard, click **Refresh access**. This signs you in to GitHub again so the
dashboard sees the new installation. A repository can take a few minutes to appear; click
**Refresh** if it is not there yet.

Check that the **Review** switch is on for the repository.

</Step>
<Step>

### Add the label to a pull request

Open a pull request in a connected repository and add the label `ai-review`. The name must
match exactly.

</Step>
<Step>

### Let CI finish

Reviewer waits until the other checks on the latest commit have passed. If the repository has
no CI at all, the review starts about two minutes after you add the label. See
[CI waiting](/docs/how-it-works#ci-waiting) to change this.

</Step>
<Step>

### Read the review

The `AI Review` check appears on the pull request while Reviewer works. When it is done, the
Reviewer bot posts its review. To see each step, open **Runs** in the dashboard.

</Step>
</Steps>
