<Callout title="The dashboard is in Russian for now">
  An English version is planned. The names below are English translations of the current labels.
</Callout>

<Steps>
<Step>

### Sign in

Open the <AppLink /> and click **Sign in with GitHub**. Sign in before you install the app, so
Reviewer can link the installation to your account.

</Step>
<Step>

### Install the GitHub App

On **Repositories**, click **Connect repository** and pick the repositories on GitHub. Each one
is connected with reviews on, and gets an `ai-review` label.

</Step>
<Step>

### Refresh access

Back in the dashboard, click **Refresh access**. The repository can take a few minutes to
appear.

</Step>
<Step>

### Add the label

On a pull request in that repository, add the label `ai-review`.

</Step>
<Step>

### Get the review

Once CI passes, the Reviewer bot posts its review. If the repository has no CI, it starts about
two minutes after the label. Follow each step in **Runs** in the dashboard.

</Step>
</Steps>

Nothing happened? See [No review appeared](/docs/faq#no-review-appeared).
