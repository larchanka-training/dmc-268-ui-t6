</Callout>

<Steps>
<Step>

### Sign in

Open the <AppLink /> and click **Sign in with GitHub** («Войти через GitHub»). If you installed the app before signing
in, your next sign-in links that installation to your account.

</Step>
<Step>

### Install the GitHub App

On <AppLink path="/repositories">**Repositories**</AppLink> («Репозитории»), click **Connect repository** («Подключить репозиторий», on an empty list «Установить GitHub App») and pick the repositories on GitHub. Each one
is connected with reviews on, and gets an `ai-review` label.

</Step>
<Step>

### Refresh access

Back in the dashboard, click **Refresh access** («Обновить доступ»). The repository can take a few minutes to
appear.

</Step>
<Step>

### Add the label

On a pull request in that repository, add the label `ai-review`. On GitHub, adding labels needs
triage access or higher.

</Step>
<Step>

### Get the review

Once CI passes, the Reviewer bot posts its review. If the repository has no CI, it starts about
two minutes after the label or the latest push, whichever is later. Follow each step in
<AppLink path="/runs">**Runs**</AppLink> («Прогоны») in the dashboard.

</Step>
</Steps>

Nothing happened? See [No review appeared](/docs/faq#no-review-appeared).
