title: Quickstart
description: Install the GitHub App and get your first review.
icon: Rocket
---

<Steps>
<Step>

### Sign in

Open the <AppLink /> and click **Sign in with GitHub**. If you installed the app before signing
in, your next sign-in links that installation to your account.

On **Repositories**, the **Get started** checklist follows these steps. See [Your first review](/first-review) for the checklist.

</Step>
<Step>

### Install the GitHub App

On <AppLink path="/repositories">**Repositories**</AppLink>, click **Connect GitHub repository** (on an empty list, **Install GitHub App**) and pick the repositories on GitHub. Each one
is connected with reviews on, and gets an `ai-review` label.

</Step>
<Step>

### Refresh access

Back in the dashboard, click **Refresh access**. The repository can take a few minutes to
appear.

</Step>
<Step>

### Check repository settings

Open the connected repository's settings. Check that **Automatic review** is on and the branch
settings cover the pull request you want reviewed.

</Step>
<Step>

### Add the label

Open a pull request in that repository and add the label `ai-review`. Today the label is required
even when **Automatic review** is on. On GitHub, adding labels needs triage access or higher.

</Step>
<Step>

### Get the review

Once CI passes, the Reviewer bot posts its review. If the repository has no CI, it starts about
two minutes after the label or the latest push, whichever is later. Follow the run in
<AppLink path="/runs">**Runs**</AppLink>, then open a successful run to read the verdict and findings.

</Step>
</Steps>

Nothing happened? See [No review appeared](/faq#no-review-appeared).

The **Get started** checklist disappears when a successful run is available. You can hide it
earlier; that choice is saved in your current browser.

Prefer a coding agent? Copy the instruction below **Try it now** on the public landing page and
paste it into your agent while it works in the target Git repository. You still approve the GitHub
App installation and device code on GitHub. The agent will receive a revocable token for that
repository, then configure reviews and read the first result without using the dashboard. The
landing instruction appears when a GitHub App slug is configured for its build.
To revoke an agent token later, open your user menu in the dashboard, choose **Agent tokens**,
and select **Revoke** for the repository's token.

Using Bitbucket Cloud? Follow [Connect Bitbucket Cloud](/bitbucket) for token scopes, webhook setup and review results.
