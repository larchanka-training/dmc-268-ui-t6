---
title: Your first review
description: Follow the in-app checklist from GitHub App installation to a review result.
---

After signing in, open **Repositories**. The **Get started** checklist guides you through your first review:

1. Install the GitHub App, choose the repositories it may access, and use **Refresh access** on the Repositories page. A repository may take a few minutes to appear.
2. Open a repository's settings. Turn on automatic review and check the branch settings for the pull requests you want reviewed.
3. Open a pull request in that repository and add the `ai-review` label. Today the label is required even when automatic review is on. After CI passes (or shortly after labeling if there is no CI), open **Runs** to see the review start.
4. Open **Runs** to read the verdict and findings. The checklist disappears when a successful run is available. You can hide it earlier with **Hide checklist**; that choice is saved in the current browser.

If either list is empty, use its action to reach the next step. A repository may be missing because the App has not been installed, the repository was not selected, or access has not yet refreshed; the empty list alone does not distinguish these cases.

For the same steps with more detail, see [Quickstart](/quickstart).
