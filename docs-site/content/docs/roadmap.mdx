## Reviews

- Automatic review of every pull request when the switch is on; the label only when it is off.
- Review only the new changes after a push, without repeating findings from earlier commits, and mark the outdated ones.
- A fuller summary at the top of the review: a checklist and what changed. Today the review body has a short summary, the risk by severity and the checked files.
- A check result that follows the verdict.
- <StatusBadge status="exploring" /> Labels on the pull request suggested by the review, if you want them.
- <StatusBadge status="exploring" /> Skip pull requests by title keywords or by author, for example bots.

## Rules

- A rules playground: paste code and rules and see a simulated review without running one on a pull request.

## Dashboard

- A review quality dashboard, a run audit log and limit notifications.
- First steps after sign-up.
