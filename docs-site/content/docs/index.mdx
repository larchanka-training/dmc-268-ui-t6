Reviewer reads the changes of a pull request and posts a review on it: inline comments, severity
levels, suggested fixes and a verdict. It works with GitHub today.

<StartHere />

## What you get

- **Inline comments** on changed lines, each with a short title, an explanation and sometimes a
  suggested change you can commit.
- **A summary** in the review body: the verdict, the number of findings per severity and the
  checked files.
- **An `AI Review` check** that shows progress.

Reviewer only reads text through the GitHub API. It never runs your code, merges or approves.
