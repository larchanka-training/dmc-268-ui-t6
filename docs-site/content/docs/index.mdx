Reviewer is a GitHub App. Add the `ai-review` label to a pull request and, once CI passes,
Reviewer posts a review with inline comments, severity levels, suggested fixes and a verdict.

<StartHere />

## What you get

- **Inline comments** on changed lines, each with a short title, an explanation and sometimes a
  suggested change you can commit.
- **A summary** in the review body: the verdict, the number of findings per severity and the
  checked files.
- **An `AI Review` check** that shows progress. It never fails, so do not make it a required
  check.

Reviewer only reads text through the GitHub API. It never runs your code, merges or approves.
