## Dashboard

<AppLink path="/runs">**Runs**</AppLink> lists every reviewed pull request with its [status](/how-it-works#details). Click a
run to see its steps, the diff with findings, and **Cancel** or **Restart**.

The dashboard is in English by default. To switch to Russian, open the profile menu at the bottom
of the sidebar and pick **RU** under **Language**, next to the theme. The choice is saved in your
browser.

## Repository settings

In the dashboard, open <AppLink path="/repositories">**Repositories**</AppLink> and click the gear next to a repository. Review rules
live in `.review/rules.md` in the repository itself, see [Rules file](/rules-file).

**Automatic review** turns reviews on or off for the repository. Today a pull request still needs
the `ai-review` label. <StatusBadge /> Soon: on reviews every pull request automatically, off
reviews only pull requests with the label.

<AutoReviewSnippet />

| Setting | What it does |
| --- | --- |
| **CI waiting** | When to start: Auto, Always or Never, see [CI waiting](/how-it-works#details). |
| **Comment limit** | How many findings are posted inline, from 1 to 10. |
| **Verdict** | Post blocking reviews as a comment or as Request changes. |

<ReviewOptionsSnippet />

| Setting | What it does |
| --- | --- |
| **Branch filter** | Review only pull requests into matching branches, for example `main` or `release/*`. Empty means all. |
| **Severity threshold** | `All`, `Warn & Crit` (drops `info`) or `Only Critical` (keeps `critical` and `high`). |

<BranchesSeveritySnippet />

<Accordions>
<Accordion title="Branch filter masks">

One mask per line, up to 20. `*` matches within one part of the name, `**` also crosses `/`.
The characters `? [ ] { } ! \ ~ ^ :` are not allowed. A pull request into a branch outside the
filter is skipped. Findings below the severity threshold are not posted; the `AI Review` check
says how many were hidden.

</Accordion>
</Accordions>

## Code index (RAG) <StatusBadge status="inactive" />

The **RAG** switch builds an index of the default branch: which symbols each file defines and
which files import each other, without the code text. Reviews already read the index while they
build their context, but its results are not sent to the model yet, so it does not change the
review and adds no model cost today.

<RagSnippet />

<Accordions>
<Accordion title="What is indexed and when it is deleted">

Python, TypeScript, JavaScript and Go files. Secrets, vendored folders, generated files and
`review-ignore` matches are skipped. The index updates after pushes to the default branch. A
build stops at fixed limits, for example a 100 MiB archive or 15 minutes, and then shows
**Error**; switch RAG off and on to try again. The index is deleted when you switch RAG off, when
the repository leaves the installation, and after 30 days without reviews. After the 30 days,
the next review rebuilds it. After you switch RAG off, switch it on again to rebuild it. A
repository that comes back to the installation with RAG on rebuilds it by itself.

</Accordion>
</Accordions>
