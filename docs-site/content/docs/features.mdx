## Repository settings

In the dashboard, open **Repositories** and click the gear next to a repository.

<RepositorySettingsMock />

| Setting | What it does |
| --- | --- |
| **Automatic review** | Turns reviews on or off for the repository. Today a pull request still needs the `ai-review` label. <StatusBadge /> Soon: on reviews every pull request automatically, off reviews only pull requests with the label. |
| **CI waiting** | When to start: Auto, Always or Never, see [CI waiting](/docs/how-it-works#details). |
| **Comment limit** | How many findings are posted inline, from 1 to 10. |
| **Verdict** | Post blocking reviews as a comment or as Request changes. |
| **Branch filter** | Review only pull requests into matching branches, for example `main` or `release/*`. Empty means all. |
| **Severity threshold** | `All`, `Warn & Crit` (drops `info`) or `Only Critical` (keeps `critical` and `high`). |

<Accordions>
<Accordion title="Branch filter masks">

One mask per line, up to 20. `*` matches within one part of the name, `**` also crosses `/`.
The characters `? [ ] { } ! \ ~ ^ :` are not allowed. A pull request into a branch outside the
filter is skipped. Findings below the severity threshold are not posted; the `AI Review` check
says how many were hidden.

</Accordion>
</Accordions>

## Code index (RAG) <StatusBadge status="inactive" />

The **RAG** switch builds an index of the default branch: which symbols each file defines and
which files import each other, without the code text. Reviews do not use it yet, so it changes
nothing and adds no cost today.

<Accordions>
<Accordion title="What is indexed and when it is deleted">

Python, TypeScript, JavaScript and Go files. Secrets, vendored folders, generated files and
`review-ignore` matches are skipped. The index updates after pushes to the default branch. A
build stops at fixed limits, for example a 100 MiB archive or 15 minutes, and then shows
**Error**. The index is deleted when you switch RAG off, when the repository leaves the
installation, and 30 days after you switched it on; switch RAG off and on to rebuild.

</Accordion>
</Accordions>

## Dashboard

**Runs** lists every reviewed pull request with its [status](/docs/how-it-works#details). Click a
run to see its steps, the diff with findings, and **Cancel** or **Restart**.
